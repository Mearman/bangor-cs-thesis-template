\chapter{Introduction}
This chapter states the problem, the contribution, and the structure of the project. It demonstrates every content type the template supports, so you can see the syntax for each.

\Useabbrev{ML} is registered once in \texttt{main.tex}. The first use expands it and later uses are short: \useabbrev{ML}. Use \texttt{\textbackslash useabbrev} mid-sentence and \texttt{\textbackslash Useabbrev} at the start of a sentence.

Cite one source in the IEEE numeric style~\autocite{knuth1984}. Reference content by label alone with \texttt{\textbackslash cref}: \cref{eq:information-gain} defines the measure, \cref{fig:crest} shows the crest through the brand layer, \cref{alg:sample} gives the shape of an algorithm, \cref{lst:sample} a code listing, and \cref{tab:sample} a results table.
