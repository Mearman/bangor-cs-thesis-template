\section{Page numbers}
This template sets the \texttt{appendixpages} class option, so each appendix is numbered on its own. The count restarts at each appendix, and the footer reads ``Appendix A - Page 1''. Remove the option from \texttt{main.tex} to continue the numbering of the main text instead.
