\chapter{Supplementary material}
Place material that supports the main text but would interrupt it here: full result tables, experiment configurations, and longer code listings.

\section{Page numbers}
Each appendix is numbered on its own. The count restarts at each appendix, and the footer reads ``Appendix A - Page n of m''. Add \texttt{appendixpages=false} to the class options in \texttt{main.tex} to continue the numbering of the main text through the appendices instead.
